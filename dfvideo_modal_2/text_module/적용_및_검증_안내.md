# 백엔드 C2·C4 수정 안내

- `app_before_asof.py`: 원본 백업
- `app.py`: 기준일 추출 확장 및 기준일 충돌 후보 후순위 처리 구현
- C4는 기본 비활성화(`USE_ASOF_RANKING=0`) 상태. **C0 테스트가 종료된 후** `USE_ASOF_RANKING=1`로 서버를 실행해야 활성화됩니다.
- 기존 날짜 없는 후보는 제외하지 않으며, 명백한 날짜 충돌 후보만 뒤로 미룹니다.
- 연도가 없는 날짜는 같은 월일인 경우 연도 불일치를 단정하지 않습니다.
- `까지`는 엄밀한 기준일이 아닌 종료일 표현일 수 있으므로 실제 자료에서 오탐 여부 확인이 필요합니다.

## 확인한 내용
- 파이썬 문법 검사 통과
- 날짜 표기 6가지 단위 검사 통과
- 날짜 충돌 비교 단위 검사 통과

## 추가 자료 필요
- `search_engine_v2/engine_meta.pkl` 등 색인 자료가 없어 1,496건 전·후 추출 수를 산출하지 못함
- `nli_model/`, 검색 엔진 모델, 진단셋 50건이 없어 C4의 실제 검색·성능 재측정을 수행하지 못함
- 실제 API 실행 및 기준일 채워진 화면 캡처 미완료
- C1·C3 프론트엔드 수정본은 별도 ZIP에 있음

## 측정 시 주의
- 신규 80건을 설정 조정 후 성능 평가에 재사용하지 마세요.
- C4 효과는 진단셋 50건에서만 확인하세요.
- 실행 당시 `app.py` SHA-256과 `USE_ASOF_RANKING` 값을 기록하세요.
