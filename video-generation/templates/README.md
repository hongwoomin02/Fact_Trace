# 합성할 원본 영상 폴더

합성에 사용할 영상을 이 폴더에 MP4로 넣으세요. 예: `01_news.mp4`, `02_interview.mp4`.
GPU 서버의 같은 폴더에도 전송해야 합니다. 확장자가 MP4인 실제 파일만 자동 등록됩니다.
프론트에서 원본 영상 선택 단계에 진입하거나 [목록 새로고침]을 누르면 반영됩니다.
파일명은 제목으로 표시되고 실제 영상으로 미리보기가 제공됩니다. JSON 수정이나 재빌드는 필요 없습니다.
본인 또는 사용 동의를 받은 영상만 넣어 주세요. 원본 영상은 Git에서 제외됩니다.

## 현재 로컬 영상 (2026-11-23)

6개 영상은 앞부분 15초, 1280×720, H.264 MP4로 변환했습니다. 원래 소리가 있던 영상은 AAC 오디오를 유지했습니다.
변환 전 파일은 `_originals_20261123_3752b102/`에 보관되어 있습니다. 백업 하위 폴더는 API 영상 목록과 전송 대상에 포함되지 않습니다.

로컬 파일을 변경해도 Vercel에서 사용하는 GPU 서버의 영상은 자동으로 바뀌지 않습니다.
저장소 루트의 PowerShell에서 다음 명령으로 GPU 서버에 전송한 뒤, 프론트에서 원본 영상 목록을 새로고침하세요.

```powershell
powershell -ExecutionPolicy Bypass -File .\video-generation\scripts\Sync-Templates.ps1
```

전송에는 GPU 서버의 SSH 인증이 필요합니다. 프론트 재빌드나 Vercel 재배포는 필요하지 않습니다.
